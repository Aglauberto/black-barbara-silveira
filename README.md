# Black Friday — Luciane Lima Estética Avançada 👑

Página ponte (*bridge page / pre-lander*) mobile-first com alta conversão para direcionamento de tráfego pago para o grupo VIP do WhatsApp.

## 🚀 Tecnologias e Recursos
- **HTML5 & CSS3 Puro**: carregamento instantâneo sem frameworks pesados.
- **Mobile First & Dark Luxury Aesthetic**: fundo escuro elegante com detalhes em dourado e verde WhatsApp.
- **CTA Otimizado (Above the fold)**: botão pulsante para entrada imediata no grupo VIP.
- **Prova Social Dinâmica (FOMO)**: notificações animadas de novos membros entrando no grupo em tempo real.
- **Node.js Preview Server**: servidor leve para testes locais.

## 📱 Visualização Local
```bash
node server.js
```
Acesse em: `http://localhost:3000`
