# Black Friday — Dra. Bárbara Queiroz 💎

Página ponte (*bridge page / pre-lander*) mobile-first minimalista, limpa e de alta conversão, em estética monocromática (Black & White) para direcionamento de tráfego pago para o grupo VIP do WhatsApp.

## 🚀 Tecnologias e Recursos
- **Visual Clean & Monocromático (Black & White)**: paleta estrita em preto, grafite e branco com acabamento de alto padrão.
- **Tipografia Delicada**: `Cormorant Garamond` (serif refinada) e `Montserrat` (pesos finos 200/300/400).
- **CTA Otimizado**: botão contrastante com pulso sutil direcionando diretamente para o WhatsApp.
- **Prova Social Dinâmica (FOMO)**: notificações flutuantes refinadas de entrada de novas pacientes em tempo real.
- **Servidor Local Node.js**: servidor estático leve sem dependências externas.

## 📱 Visualização Local
```bash
node server.js
```
Acesse em: `http://localhost:3000`
